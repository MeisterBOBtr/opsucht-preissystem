# Lizenzstatus

Für das Repository ist in dieser Dokumentation noch keine endgültige Open-Source-Lizenz festgelegt.

Vor einer öffentlichen Verteilung des Add-ons sollte geklärt werden:

- Welche Lizenz für den eigenen Quellcode verwendet werden soll.
- Ob und wie das Rahmenbild, Logos und andere Ressourcen weitergegeben werden dürfen.
- Welche Bedingungen OPSUCHT für die Nutzung von Namen, Marken und API-Daten vorgibt.
- Ob Abhängigkeiten oder Mod-Loader-Bibliotheken eigene Lizenzbedingungen haben.

Bis zur Klärung sollte nicht angenommen werden, dass alle enthaltenen Dateien beliebig weiterverwendet oder weiterverteilt werden dürfen.
